# XML Assistant · XML 大纲

在 VS Code 中浏览 XML 标签树、搜索内容、统计标签，并用明亮的彩色标签快速筛选。

## 安装与使用

需要 VS Code **1.90.0 或更新版本**。

1. 在扩展面板右上角菜单选择 **从 VSIX 安装… / Install from VSIX…**，选择构建生成的 `xml-assistant-0.1.1.vsix`。
2. 打开 XML 文件，在资源管理器中展开 **XML 大纲**。也可运行命令 **XML Assistant: 打开 XML 大纲**。
3. 大纲默认只显示标签名。点击齿轮，勾选 **显示所有属性** / **显示文本内容**；设置对所有层级生效并自动保存。
4. 在顶部搜索框输入标签名、属性名、属性值或文本。`.*` 开启 JavaScript 正则，`Aa` 切换大小写敏感；Esc 清空搜索。
5. 搜索栏下方显示每种标签的数量。点击彩色标签，只隐藏或恢复该类别的标签，其他类别的子节点继续显示；**全部显示**恢复所有标签。
6. 点击树节点定位源码；点击节点左侧箭头折叠或展开。支持方向键、Home / End 和 Enter / 空格。

**视图说明：** VS Code 公共扩展 API 不允许在原生 Outline 内插入搜索框、统计栏或任意彩色图标。因此完整交互集中在资源管理器的 **XML 大纲** Webview 视图，可拖动到偏好的侧栏位置。同时注册 DocumentSymbolProvider，为原生 **Outline / 大纲** 和面包屑提供标签树与显示设置；原生图标颜色由 VS Code 主题控制。若安装了其他 XML 扩展，原生 Outline 可能优先选用其符号提供器，完整功能仍可在 XML 大纲中使用。

## 搜索与统计规则

- 标签按完整名称（包括命名空间前缀）分组，大小写不同的标签独立统计。统计数字始终来自整份文档，不随搜索或隐藏改变。
- 搜索覆盖四种字段，不受属性、文本显示开关影响。结果只保留匹配节点及其祖先，显示首个命中字段的高亮片段，方便确认隐藏属性或文本的匹配原因。
- 每个标签类别独立控制。隐藏父标签后，其未被隐藏的子节点提升到最近的可见祖先下；没有可见祖先时显示为顶层，保持源码顺序。恢复父类别不会恢复其他已隐藏的类别。隐藏节点的折叠状态不影响提升后的子节点，可见节点仍可正常折叠。
- 搜索可穿过隐藏的祖先找到未隐藏的后代，并保留可见祖先层级；不会恢复手动隐藏的类别。搜索结果数为当前筛选下匹配的标签数。
- 文本指元素的直属文本及 CDATA，首尾空白移除，子元素的文本归属于子元素。XML 内置实体与数字字符引用会解码后参与搜索。
- 支持命名空间、自闭合标签、中文、Unicode、注释、处理指令和 DOCTYPE。注释、处理指令与 DOCTYPE 不计入标签统计。
- 自定义 DTD 实体和外部实体不会展开；不读取外部文件或网络。需要这些实体才能解析的文件会显示解析提示及可用部分结果。
- 文档编辑后约 200ms 更新。切换文件时保留该文件的标签筛选与折叠状态；内容变化后重置折叠状态，避免节点位置变化导致错误关联。

## 设置

可使用侧栏齿轮，或在 VS Code 设置页搜索 `XML Assistant`。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| `xmlAssistant.showAttributes` | `false` | 所有层级显示全部属性及属性值 |
| `xmlAssistant.showText` | `false` | 所有层级显示直属文本与 CDATA |
| `xmlAssistant.maxFileSizeMB` | `20` | 文件解析上限，范围 1–100 MiB |

UI 开关优先更新已存在的工作区 / 文件夹设置，否则保存为用户设置。

## 大文件与错误处理

- 每个文件最多解析 **100,000 个元素**；超出时明确提示当前为部分结果。
- 标签树首次显示最多 1,000 个可见节点，可点击 **显示更多**继续加载。
- 正则搜索在独立 Web Worker 中执行，运行超过 1 秒会终止并提示，修改表达式即可重试。
- XML 暂时不完整或格式错误时显示解析提示与可用结构，不将部分统计伪装成完整结果。
- 数据在本机处理，不上传 XML 内容。支持未信任工作区和 VS Code 桌面端 / 远程扩展宿主；此版本不是浏览器端 Web Extension。

## 开发

使用 Node.js 20.19+ 和 npm，在当前插件目录运行：

```sh
npm ci
npm run compile
npm test
npm run package
```

在 VS Code 中打开本目录，按 F5 运行 **运行 XML Assistant**，自动打开 [示例 XML](./examples/catalog.xml)。

- [扩展入口](./src/extension.ts)：Webview、配置、编辑器联动和原生 Outline。
- [解析模型](./src/model.ts)：基于 SAX 的解析、源码偏移及统计。
- [侧栏交互](./media/outline.js) / [样式](./media/outline.css)：搜索、筛选、树与设置。
- [搜索 Worker](./media/search.js)：独立线程正则搜索。
- [测试](./test/)：解析、源码范围、搜索、宿主接口、DOM 交互与超时保护。

`node test/preview.cjs` 提供本地浏览器预览（`http://127.0.0.1:4318`），使用真实侧栏资源与模拟 VS Code 桥接；它不替代扩展宿主测试。真实宿主测试入口为 [host-integration.cjs](./test/host-integration.cjs)，可通过 VS Code CLI 的 `--extensionDevelopmentPath`、`--extensionTestsPath` 和隔离的 `--user-data-dir` 运行。

本地 VSIX 使用 `xml-assistant-local` 作为 publisher；发布 Marketplace 前请替换为自己已注册的 publisher。
